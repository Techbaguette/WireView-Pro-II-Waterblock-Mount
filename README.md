# WireView Pro II GPU Waterblock Mount

![WireView Pro II installed on GPU waterblock](20261002_100705)

A custom 3D-printable mounting bracket designed to install the **Thermal Grizzly WireView Pro II (Normal, non-Wired version)** next to a vertically mounted GPU using a PCIe riser.

The bracket attaches directly to the GPU waterblock using two open hooks that fit around existing spacer/standoff locations. It provides a clean, secure installation **without adhesives or pressure on the GPU PCB**, while keeping the WireView display, button, connectors and ventilation accessible.

The design has been **physically printed, installed and tested** on the following hardware:

- **GPU:** MSI GeForce RTX 5090 Suprim X
- **Waterblock:** Alphacool Core GeForce RTX 5090 Suprim / Vanguard / Gaming Trio with Backplate (Article No. 10268)
- **Monitoring device:** Thermal Grizzly WireView Pro II Normal (H19N)
- **GPU mounting:** Vertical, using a PCIe riser

## Compatibility and Adaptation

This mount may also be adapted to other GPU waterblocks with a similar construction. The vertical bar dimensions, hook spacing and rear retaining tab position may need adjustment depending on the waterblock.

**Detailed instructions for adapting the design are provided in the included "How to Adapt to Your Waterblock" README file.**

The design may also be adapted to the **WireView Pro II Wired version** by increasing the internal depth of the cradle. An estimated **34 mm internal clearance** may work, but this has not been tested and must be verified.

## Download and 3D Printing

The files include:

- **STL:** Ready for 3D printing.
- **STEP:** Editable CAD model for customization.

The final version was successfully printed in **white PETG**.

**Important:** Print at 100% scale on all axes. Do not resize the model, as several dimensions are critical for proper installation.

Always check compatibility and clearances before installing the bracket on your hardware.
